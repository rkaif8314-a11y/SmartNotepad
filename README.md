# SmartNotepad

A modern cloud-based note-taking application built with Next.js, React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Next.js 15** application
- **React 19** interface
- **Cloud notes** with Supabase
- **Authentication** with Supabase Auth
- **Persistent user data**
- **Responsive note editor**
- **Modern Tailwind CSS interface**

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## 🛠️ Run Locally

```bash
npm install
npm run dev
```

Open the local development server shown by Next.js.

## 📦 Production Build

```bash
npm run build
npm run start
```

## 🔐 Environment Variables

Configure the required Supabase environment variables in `.env.local`.

Never commit production secrets or API keys to GitHub.
